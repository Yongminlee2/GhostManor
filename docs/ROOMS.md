# 방별 퍼즐 설계 (⚠️ 전체 스포일러) — 리마스터판

각 방의 스레드 구조, 정답 체인, 방을 넘는 아이템을 기록한다.
코드의 유일한 진실은 `lib/rooms/roomN_*.dart`이며, 이 문서는 그 요약이다.
정답 체인은 `test/solutions.dart`의 `solveXxx`(스텝 수 반환)와 1:1로 대응한다.

## 하드코어 규칙 (전 방 공통 — `test/hardcore_metrics_test.dart`가 강제)

- 방마다 벽면 3개, 상호작용(핫스팟) ≥15, 정답 시퀀스 ≥15스텝, 챕터 합계 ≥100스텝.
- 진입 직후 서로 다른 퍼즐 스레드 2개 이상이 착수 가능(병렬), 서로 교차 잠금.
- 단서는 원형 그대로 못 쓴다 — 최소 1회 변환·조합을 거쳐야 답.
- **지식은 게이트가 아니다**: 단서(편지·낙서·레시피·쪽지·지도·자수)는 "답을 아는
  방법"일 뿐, 안 보고도 조작이 맞으면 통과한다. 각 방 부정 테스트가 이를 고정.
- 유령 대사에 정답 직결 정보 금지. 힌트는 방 진입 5분 후 1단계, 이후 3분당
  1단계 해금(`HintService` 시간 잠금), 3단계는 문자 그대로의 정답.

## 방 1 — 현관 (튜토리얼) `foyer_r_*` — 18스텝

T1 빛 만들기 ‖ T2 시계 코드, 교차: 서랍 안이 어두워 T1의 불 켠 초 필요.

```
T1: 외투 문지르기 → 성냥 · 신발장 구두 3켤레 중 하나 → 양초 · 조합 = 불 켠 초
T2: 액자 문지르기 → 복도 시계 4개 그림(1·7·3·11시) · 우편함(클로즈업) → 편지
    "저녁 식사는 셋째 시계의 시각에" ⇒ 셋째 시계 = 3시 → 벽시계를 3시로 → 서랍 해금
교차: 서랍(어두움) ← 불 켠 초 → 낡은 열쇠 → 안쪽 문 → 클리어
```

- 편지는 지식(없어도 시계 3시면 서랍 열림 — 부정 테스트).
- 벽 C(계단참): 우편함·거울("유령이 안 비친다")·초상화 2점·장식 문·촛대·양탄자.

## 방 2 — 거실 `living_r_*` — 32스텝

T1 초상화 금고 ‖ T2 촛대→벽난로 ‖ T3 TV, 교차: T2 비밀칸의 다이얼 손잡이가
T1 금고에 필요, T3 TV가 T1(나이순)·T2(촛대 패턴) 단서를 겸함.

```
T3: 쿠션 → 리모컨 → TV 켜기(부우 비켜남) · 화면 순환: 촛대 패턴 ↔ 나이 행렬
T2: 촛대 [꺼짐,켜짐,꺼짐,켜짐] → 벽난로 점화 + 비밀칸 → 다이얼 손잡이
T1: 초상화 4점(그림 속 소품이 매핑 단서: 아기=램프, 청년=괘종, 중년=꽃병,
    노인=책) × 소품 탭 개수(램프 줄무늬 3 · 추 2 · 꽃 7 · 책 4) × TV 나이순
    ⇒ 3274 → 손잡이 장착 → 다이얼 금고(DialSafe, 4자리) → 열쇠+기름병+♪달
문 → 클리어
```

- 코어 위젯: `DialSafe`(순수 함수 `tapDialWheel`/`checkDialCode`, digits 파라미터).
- **다음 방으로: 기름병, ♪달.**

## 방 3 — 서재 `study_r_*` — 17스텝

T1 별자리 관측 ‖ T2 문양-색 변환 책 순서, 교차: T2 숨은공간의 렌즈가 T1 망원경 부품.

```
T2: 잉크 종이 문지르기 → 문양 순서(꽃→나무→새→뱀) · 책등 각인(빨=새, 파=꽃,
    노=뱀, 초=나무) ⇒ 변환: 파→초→빨→노 → 색 책 탭 → 숨은공간 → 렌즈+♪별
T1: 망원경+렌즈 → 관측(별 5개 W자) → 지도(W=여우자리, 화살표 셋) ⇒ 지구본
    화살표 정확히 3탭 → 반쪽이 실이동으로 벌어짐(SceneObject) → 틈에서 열쇠
문: 열쇠 + 기름병(경첩) → 클리어
```

- 지구본은 2핫스팟: 화살표(카운트, 4탭째 리셋)와 틈(taps==3에서만 열쇠).
- 벽 B 베이스는 플레이트(지구본 제거+열쇠 노출), 반쪽 2개가 닫힘 상태를 덮는다.
- **소비: 기름병(방 2). 다음 방으로: ♪별.**

## 방 4 — 주방 `kitchen_r_*` — 21스텝

T1 유령 수프(월드 냄비 슬롯) ‖ T2 빙실, 교차: 빙실의 마른 약초가 수프 3번째 재료.

```
T2: 저장실 부지깽이 → 화덕에 달굼(poker→poker_hot) → 빙실 언 자물쇠에 3회
    → 서리→물방울→개방 → 마른 약초 + ♪해
T1: 레시피판 문지르기(물방울→버섯→잎→음표, 지식) · 재료를 냄비에 순서 투입:
    물(싱크대) → 버섯 → 약초 → 주전자(노래를 부음) — 단계마다 냄비 그림 변화,
    틀리면 국자 오답 대사 + 오답 프레임 + 물부터 리셋
완성 수프 → 국자 → 뒷문 열쇠 → 클리어
```

- 순수 함수: `usePotIngredient`, `meltIce`. **다음 방으로: ♪해.**

## 방 5 — 지하실 `cellar_r_*` — 21스텝

T1 전력 복구 ‖ T2 와인 연도 코드, 어둠↔점등 왕복이 정체성(야광 단서 3곳은
어둠에서만, 라벨 판독·통 밀기는 점등에서만 — 왕복 ≥2회를 테스트가 단언).

```
(어둠) 상자A 야광 → 퓨즈1 · 배전반 옆 낙서 → 스위치 순서 △○□ · 랙 옆 낙서
    → "촛불 다섯→하나→셋"
(점등) 병 5개 라벨(촛불 개수) → 5→1→3 순서 탭 → 상자B → 퓨즈2 + ♪구름
퓨즈 2개 장착 → SwitchPanel △○□ → 전력 복구(점등 고정)
통 밀기(SceneObject 실이동) → 쪽문 노출 · 셰이크(또는 선반 10연타) → 열쇠 낙하
열쇠+전력 → 쪽문 → 클리어
```

- 코어 위젯: `SwitchPanel`(순수 함수 `flipSwitch`). 쪽문은 전력도 요구(스위치
  퍼즐 우회 방지). 납품 아트의 라벨 중복(병1·5 둘 다 촛불 3)은 촛불 "개수 값"
  판정으로 흡수 — 어느 3병이든 통과.
- **다음 방으로: ♪구름.**

## 방 6 — 다락방 (최종) `attic_r_*` — 25스텝

T1 오르간 연주 ‖ T2 작은 궤짝, 교차: 궤짝 속 자수 조각이 연주 순서의 나머지 반.

```
T2: 낡은 쪽지(촛불·창·책 그림+물음표, 지식) ⇒ 다락 소품 개수 세기:
    촛대 양초 3 · 창 격자 4 · 책 더미 2 ⇒ 342 → 궤짝(DialSafe 3자리) → 자수 조각
T1: 찢긴 자수(달→해→?→?) + 조각 = 달→해→별→구름 · 카드 4장 배치(달=도 별=레
    해=미 구름=파) ⇒ 연주 [1,3,2,4] → 트렁크 → 유언장(반전) → 챕터 종료
```

- DialSafe를 digits:3으로 재사용(flagPrefix 분리로 거실과 충돌 없음).
- 엔딩 흐름(유언장·클리어 전진·자가 치유 가드)은 구세대와 동일 구조.
