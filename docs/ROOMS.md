# 방별 퍼즐 설계 (⚠️ 전체 스포일러)

각 방의 정답 체인, 사용 플래그, 방을 넘는 아이템을 기록한다.
코드의 유일한 진실은 `lib/rooms/roomN_*.dart`이며, 이 문서는 그 요약이다.
정답 체인은 `test/solutions.dart`의 `solveXxx` 함수와 1:1로 대응한다.

## 공통 규칙

- 방 이동은 앞으로만 간다(뒤로 못 감). 따라서 **방을 넘는 단서는 반드시
  아이템**(자동 휴대)이고, 시각 기억 단서는 같은 방 안에서 소비된다.
- 방을 넘는 아이템은 전부 필수 진행 보상과 같은 액션에서 지급된다 —
  놓치고 다음 방으로 갈 수 없다.
- 힌트는 퍼즐당 3단계(방향→구체→정답), 마지막 단계는 문자 그대로의 정답.

## 방 1 — 현관 (튜토리얼) `foyer_*`

목적: 탭 / 아이템 획득·사용 / 조합 / 벽면 전환 / 클로즈업 / 문지르기 / 교차 단서 학습.

```
외투 → 성냥 · 신발장(클로즈업) → 양초 · 조합 = 불 켠 초
액자 먼지 문지르기 → "시계가 3시" 그림 → 벽시계 시침을 3시로 → 서랍 해금
서랍(어두움) ← 불 켠 초 사용 → 낡은 열쇠 → 안쪽 문 → 입장(클리어)
```

- 커스텀: `ClockCloseup`(시침 탭 순환), `RubbableScene`(먼지).
- 유령: 고스포(집사) — 인트로·리액션 담당.

## 방 2 — 거실 `living_*`

기믹: 클릭 패턴, 상태 변화(TV·벽난로), 유령 상호작용.

```
쿠션 → 리모컨 → TV 켜기(부우가 문 앞에서 소파로 비켜남 + 화면에 단서)
TV 화면: 촛대 4개 중 2·4번만 점화된 그림
촛대 토글로 [꺼짐,켜짐,꺼짐,켜짐] 완성 → 벽난로 점화 + 비밀칸 개방
비밀칸 → 거실 열쇠 + ♪달 카드 + 기름병 → 문 → 클리어
```

- 순수 함수: `toggleCandle` (패턴 검사 내장, 점화 후 불가역).
- 주의: 문 핫스팟이 부우 rect를 품는다 — 부우가 나중에 선언되어 자기 영역 탭을
  받는다(z순서 규칙의 실전 사례).
- **다음 방으로 가는 아이템: 기름병, ♪달.**

## 방 3 — 서재 `study_*`

기믹: 문지르기, 순서 입력, 교차 단서(기름병 소비), 이중 잠금.

```
책상 종이(잉크) 문지르기 → 색 순서: 파랑→초록→빨강→노랑
색 책을 그 순서로 탭(틀리면 리셋+대사) → 책장 숨은 공간 → 크랭크 + ♪별
크랭크를 지구본에 → 서재 열쇠
문: 열쇠(잠금 해제) + 기름병(녹슨 경첩) 둘 다 → 클리어  ※순서 무관
```

- 순수 함수: `tapBook` (정답 [파,초,빨,노] = 내부 인덱스 [2,4,1,3]).
- 납품 아트에 맞춰 좌표 미세조정 이력 있음(책 선반 한 칸 위) — `art/room3-assets.md` 참조.
- **소비: 기름병(방 2). 다음 방으로: ♪별.**

## 방 4 — 주방 `kitchen_*`

기믹: 다단계 조합, 사운드 단서(음소거 대응은 대사로).

```
조리대 → 빈 병 · 싱크대에 병 사용 → 이끼물 병 · 항아리 → 말린 버섯
찬장 4개 두드리기 → 속 빈 소리(2번 문) → 노래하는 주전자
조합: 버섯+이끼물=수프 베이스 → 베이스+주전자=유령 수프
국자에게 수프 → 뒷문 열쇠 + ♪해 → 뒷문 → 클리어
```

- 조합 테이블 키는 사전순 정렬 결합(`kettle_singing+soup_base` 등) — items.dart.
- 두드림 판정은 대사 텍스트로도 구분된다(둔탁 vs 울림) — 청각 없이도 공정.
- **다음 방으로: ♪해.**

## 방 5 — 지하실 `cellar_*`

기믹: 어둠/야광 상태, 드래그, 폰 셰이크(+연타 폴백).

```
(어둠) 야광 표시가 가리키는 상자 → 퓨즈 + ♪구름
퓨즈를 배전반에 → 스위치 → 점등 (끄면 야광 단서 다시 보임 — 재관찰 가능)
와인통 클로즈업: 드래그로 끝까지 밀기 → 숨은 쪽문 노출
선반 클로즈업: 폰 흔들기(가속도 크기>12) 또는 10연타 → 열쇠 낙하
바닥 열쇠 줍기 → 쪽문 → 클리어
```

- 순수 함수: `moveBarrel`(진행도 0~100 누적·캡), `dropShelfKey`(점등+미낙하 게이트),
  `tapShelf`(연타 카운터).
- 오버레이 선언 순서가 규칙: 어둠막(전면) 먼저, 야광은 뒤(위에 그려짐).
- 센서 경로는 자동 테스트 불가 — 실기기 검증 항목. 연타 폴백이 테스트 경로.
- **다음 방으로: ♪구름.**

## 방 6 — 다락방 (최종) `attic_*`

기믹: 교차 단서 총집결(카드 4장 소비), 순서 연주, 반전 엔딩.

```
♪달·♪별·♪해·♪구름 카드 4장을 보면대에 배치 (음 매핑: 달=도 별=레 해=미 구름=파)
자수 클로즈업: 달→해→별→구름  ⇒  연주 순서 = 도·미·레·파 (건반 1·3·2·4)
오르간 연주 성공 → 트렁크 개방 → 유언장("삼촌도 유령이었다") → 재탭 → 챕터 종료
```

- 순수 함수: `tapOrganKey` (카드 4장 게이트, 정답 [1,3,2,4], 오답 리셋,
  연주 완료 후 no-op).
- 유의: 첫 탭부터 틀리면 별도 오답 연출이 없다(진행 0→0은 리셋이 아님) —
  음 자체는 재생되므로 자유 연주처럼 느껴진다. 의도된 설계.

## 챕터 무결성

`test/chapter1_integration_test.dart`가 하나의 GameState로 여섯 방을 연속
클리어하며 경계를 검증한다: 서재 진입 전 기름병 보유, 다락 진입 전 카드 4장 보유.
방을 수정하면 이 테스트가 방 간 배선 파손을 즉시 알린다.
