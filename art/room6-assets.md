# 다락방(room6_attic) 에셋 의뢰 목록

> 납품 아트에 맞춰 좌표 미세조정 반영 — 코드와 일치.

공통 접두어는 style-guide.md 참조. 완성 파일은 그대로 아래 경로에 저장 (코드 수정 불필요).

이 방은 **교차 단서 총집결** 방이다 — 카드 그림 자체가 음 매핑(♪달=도, ♪별=레, ♪해=미,
♪구름=파)을 나타내고, 이 방의 벽걸이 자수가 연주 순서(달→해→별→구름 = 도→미→레→파 =
건반 1·3·2·4)를 알려준다. 신규 아이템은 없다 — note1~4(음표 카드)는 방 2~5에서 이미 회수한
그림 그대로 재사용된다(카드 자체에 별도 다락방용 아트 불필요).

## 아이템
이번 방은 신규 아이템 없음 — note1~4(음표 카드, ♪달·♪별·♪해·♪구름)는 방 2~5에서 이미
발급된 assets/items/note1~4.png를 그대로 소비만 한다(다락방 전용 아트 불필요).

## 효과음
신규 4개: **note1, note2, note3, note4** — 오르간 건반 도·레·미·파 각각의 짧고 또렷한
단음(건반을 눌렀을 때 나는 개별 음, 없으면 무음 폴백이라 필수는 아니지만 있으면 연주감이
살아남). 나머지는 기존 재사용 — ghost_giggle, sparkle, unlock, locked, door_open
(clock_tick은 이번 방에서 미사용).
