# 리터치 의뢰 2차 (리마스터 아트 검수 결과)

공통 규칙은 `art/style-guide.md` 그대로 (확정 프롬프트 접두어, 원본 edit 방식,
텍스트·숫자 금지, 투명 PNG 규격). 아래 파일명 그대로 저장.

## 필수 (퍼즐 정합성)

1. **foyer_coat_dust.png / foyer_coat_clean.png** (신규 2장, 각 1024×1024)
   - 현관 외투 클로즈업 문지르기 쌍 — 이번 납품에서 빠진 파일.
   - dust: 벽걸이 외투(검은 코트)가 먼지를 뒤집어쓴 클로즈업.
   - clean: 같은 구도에서 먼지가 걷히고, 가슴 주머니에 성냥갑이 삐죽 보이는 상태.
   - dust는 clean을 이미지 입력으로 넣고 먼지만 얹는 edit로(구도 동일 필수).

2. **study_paper_clean2.png** (재생성, 1024×1024)
   - 현재본은 문양 4개(꽃→나무→새→뱀)의 타일 배경이 유색(보라·파랑·빨강·노랑)이라
     "문양→책등 각인→색" 변환 퍼즐의 답을 절반은 미리 주고 절반은 틀리게 오도함.
   - **타일 배경을 전부 동일한 무채색(양피지 톤)으로**. 문양·화살표·구도는 현재와 동일.
   - 현재 파일을 이미지 입력으로 넣고 타일 배경색만 고치는 edit 권장.

3. **study_stars.png** (재생성, 1024×1024)
   - 망원경 관측 원형 뷰의 별 5개가 현재 V자(아래로 볼록) 배열 —
     지도(study_starmap.png)의 W자와 매칭이 안 됨.
   - **별 5개를 W자(지그재그: 위-아래-위-아래-위) 배열로**. 지도의 W와 같은 형태.
   - 원형 프레임·구름·톤은 현재와 동일하게.

4. **boo_sofa.png** (재생성 — 지난 1차 요청 유지, 투명 PNG)
   - 소파 위 부우: 본편 부우와 같은 그림체·같은 얼굴로, 배경 없이 전신.

## 권장 (일관성 — 있으면 반영, 없어도 게임은 동작)

5. **cellar_c.png**: 와인병 5개 라벨의 촛불 개수가 현재 3·1·5·2·3 —
   1번과 5번이 중복. **1~5개가 하나씩만 나오게**(예: 4·1·5·2·3) 라벨만 수정.
6. **living_c.png**: 좌하단 책 더미가 3권으로 보임 — 대사·정답은 "네 권"이니
   **4권으로**(얇은 책 한 권 추가) 해당 부분만 edit.
7. **kitchen_c.png**: 우측 걸이의 도구가 삽(shovel)처럼 보임 —
   **부지깽이(끝이 갈고리진 긴 쇠막대)로** 해당 부분만 edit.
8. **kitchen_c_ice1~3.png**: 현재 크롭이 빙실 문이 아니라 게시판·병 쪽 —
   **빙실 함 문(자물쇠 포함) 영역 크롭**으로 서리→물방울→활짝 3단계.
   kitchen_c.png의 함 문 부분(왼쪽 대형 함)을 원본 edit 후 같은 창으로 크롭.
