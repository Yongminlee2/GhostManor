# GhostManor 아트 스타일 가이드 (이미지 생성 프롬프트)

모든 이미지 프롬프트 앞에 붙이는 공통 접두어:

> 코믹 호러 카툰 스타일, 두꺼운 다크 초콜릿색 외곽선, 보라·남색 어두운 톤에
> 따뜻한 촛불 오렌지 포인트 조명, 귀엽지만 으스스한 분위기, 낡은 빅토리안 저택,
> 텍스트·글자 없음, 모바일 게임 배경 일러스트

규칙:
- 벽면 씬: 1024×1536 세로. 화면에 글자·숫자 넣지 않는다(단서는 그림·기호로).
- 클로즈업: 1024×1024.
- 아이템: 512×512, 배경 투명(PNG), 사물 하나만 중앙에.
- **오버레이(사물·상태 변화): 반드시 원본 씬 파일을 이미지 입력으로 넣고 해당 부분만 수정(edit)한다.** 새로 그려서 잘라 붙이면 픽셀이 안 이어져 사각 이음새가 생긴다(방 3~6 1차 납품에서 실제 발생 — retouch-request-1.md). 상태 변화가 큰 오버레이는 전체 프레임(1024×1536)으로 받는 것을 우선한다.
- **오버레이(유령·캐릭터): 배경 없이 캐릭터만, 전신이 잘리지 않게, 배경 투명(PNG).** 씬 크롭 방식 금지 — 배경이 함께 구워지면 벽에 겹칠 때 이중으로 보인다. (현관 ghost_butler에서 실제 발생한 문제)
- 첫 방(현관) 생성에서 톤이 확정되면 이 문서에 확정 프롬프트를 기록하고 이후 전 에셋에 동일 적용.
- 방 1개 분량씩 생성→게임에서 확인→다음 방 (스펙 §5.3).

## 방 1(현관) 확정 프롬프트

> 코믹 호러 카툰 스타일, 두꺼운 다크 초콜릿색 외곽선, 보라·남색 어두운 톤에
> 따뜻한 촛불 오렌지 포인트 조명, 귀엽지만 으스스한 분위기, 낡은 빅토리안 저택,
> 정면 고정형 모바일 게임 카메라, 또렷한 실루엣, 손으로 그린 듯한 낡은 목재·벽지 질감,
> 텍스트·글자·숫자·워터마크·로고 없음, 모바일 게임 배경 일러스트
