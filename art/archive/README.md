# 아트 보관함

리터치 작업 과정에서 나온 **중간본·후보본·미채택본**을 모아 둔다. 게임에는
쓰이지 않는다(`pubspec.yaml`의 에셋 경로는 `assets/` 하위뿐이라 앱 용량과
무관하다). 나중에 다른 상태 그림을 합성하거나 구도를 다시 참고할 때 쓰려고
남긴다 — 벽면 전체가 담긴 원본이 있어야 일부만 잘라 쓰는 작업이 가능하다.

채택본은 `assets/scenes/`·`assets/items/`에 들어가 있고, 이 폴더의 파일과
이름이 다를 수 있다. 의뢰 내용은 `art/retouch-request-*.md` 참조.
