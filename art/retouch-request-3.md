# 리터치 의뢰 3차 (챕터 2 검수 결과)

공통 규칙은 `art/style-guide.md` 그대로. **전부 기존 파일을 이미지 입력으로 넣은
edit**(새로 그리면 픽셀 안 이어짐). 완성본은 같은 파일명으로 덮어쓰기.

## 필수 — 문이 그려지지 않은 벽 3장

챕터2 의뢰서(2차)에서 문 명세가 누락돼 방을 나가는 문이 그림에 없다.
각 벽의 **비어 있는 쪽 가장자리에 닫힌 목재 문 1개**를 추가(현관·계단홀
문들과 같은 양식: 아치 상단, 어두운 목재, 놋쇠 손잡이).

| 파일 | 문 위치 |
|---|---|
| f2_bed_a.png | 오른쪽 가장자리(신발장·협탁 반대편), 벽등 옆 |
| f2_child_a.png | 오른쪽 가장자리(협탁 옆 빈 벽) |
| f2_lab_a.png | 오른쪽 가장자리(책장 옆 빈 벽) |

## 필수 — 안방 거울상 정합

`f2_bed_mirror.png` 재생성: 현재는 좌우반전이 아니고 보석함까지 빠져 있어
"거울에 안 비치는 유령 물건 찾기" 단서가 흐리다.
- **f2_bed_b.png를 입력으로 정확한 좌우반전 구도**로 만들고,
- 반전본에서 **브로치만 지운다**(화장대 위 보라 보석).
- 촛대·보석함·의자·액자는 반전된 위치에 그대로 있어야 한다.

## 권장 — 계단홀 카펫 단서 명확화

`f2_hall_c.png`: 카펫 가장자리 다이아 4개가 **위→아래 한 줄로 1·2·3·4**
읽히도록 정렬하고 **2번째와 4번째만** 속을 채운다(현재는 좌우로 흩어져
순서 대응이 모호 — 관찰 대사로 임시 보완해 둔 상태).
연동: `f2_hall_c_rolled.png`/`f2_hall_c_plank.png`도 같은 카펫 수정을
반영해 재생성(각각 원본 edit 체인 유지).

## 권장 — 그림체 통일 (선택)

`edgar_ghost.png`·`living_b_boo_sofa.png`: 본편 유령들(고스포 등)보다
선이 얇고 매끈한 스티커풍 — 두꺼운 다크 초콜릿 외곽선+낡은 질감으로
재생성하면 톤이 붙는다. 실기기에서 확인 후 결정해도 됨.
