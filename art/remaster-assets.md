# 리마스터 아트 일괄 의뢰서 (배경판+스프라이트 · 신규 벽면 6 · 상태 시리즈)

목적: Task 4~9(현관·거실·서재·주방·지하실·다락방 리마스터) 설계표에 필요한 신규 이미지 전량을 한 문서로 모아, 이미지 생성 작업을 코드 구현과 병렬로 진행한다.

공통 규칙:
- 모든 프롬프트 앞에 style-guide.md의 "방 1(현관) 확정 프롬프트"를 그대로 붙인다.
- **"입력 파일" 표기가 있는 항목은 반드시 그 파일을 이미지 입력으로 넣고 지정 부분만 수정(edit)한 전체 그림을 돌려받는다.** 새로 그려서 잘라 붙이면 이음새가 생긴다(retouch-request-1.md 전례). 입력 파일이 이 문서의 다른 행에서 먼저 생성되는 파일이면(예: kitchen_pot2.png의 입력이 kitchen_pot1.png), 그 파일이 먼저 도착한 뒤 순서대로 진행한다.
- 화면에 글자·숫자를 넣지 않는다. 단, **개수·기호 자체가 퍼즐 단서인 그림**(시계 바늘 위치, 촛불 개수, △○□ 기호, 화살표 개수, 동물·식물 문양 등)은 문자가 아닌 "그림"으로 표현한다 — 숫자 형태(1,2,3…)나 알파벳은 금지, 눈으로 세거나 모양으로 구분하는 그림은 허용.
- 캐릭터·발광체 오버레이(유령, 야광 낙서 등)는 배경 없이 대상만, 배경 완전 투명 PNG로 받는다.
- 완성 파일은 그대로 assets/scenes/(씬·오버레이·클로즈업) 또는 assets/items/(아이템) 아래 저장한다(코드 수정 불필요, 파일명 일치만 확인).
